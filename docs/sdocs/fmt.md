# std.fmt

String formatting utilities.

## Functions

### `print_label(label: String, value: Int) -> Void`
Prints a label string followed by an integer value.

### `format_int(value: Int) -> String`
Converts an integer to its string representation. (Work in progress)

## Examples

```nimble
load std.fmt

fmt.print_label("score: ", 100)
```
